Scan analysis

One frame in. Four scores out.

Choose a lung CT frame from your device or start with a sample. Cancaria returns the model's predicted class, every class score, and a structured report you can download.

Checking inference service

One image is sent to this server for classification. It is held in memory for 30 minutes so the report can be generated, and is never written to disk.

  2. 02 Inference ResNet-18 forward pass

What leaves your device

Only the selected image is uploaded. No patient metadata is read or sent, and no scan is passed to an external AI provider.
